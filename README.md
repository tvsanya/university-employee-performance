# Анализ эффективности сотрудников университета

Тема: «Автоматизация процессов оценки эффективности работы сотрудника университета с применением интеллектуального анализа данных».
Автор: Бакулин Александр Максимович (`tvsanya`).

Приложение загружает CSV из файла или HTTP/HTTPS-ссылки, проверяет структуру, обучает базовые модели и многослойную нейросеть, подбирает параметры по validation, сравнивает метрики и применяет выбранную модель. В интерфейсе доступны фоновые задания, графики, важность признаков, анализ вероятностей, устойчивости и неопределённости, скачивание модели и архива исследования. Подготовка признаков обучается только на train; сотрудники не пересекаются между выборками.

Комплектные данные **симуляционные**: 1500 условных сотрудников, два периода, 3000 строк и 16 колонок. Они выбраны для разработки и демонстрации. Метрики не подтверждают качество оценки реальных сотрудников. Происхождение synthetic и назначение development_demo_only сохраняются в результатах.

## Запуск

Python 3.12 или новее:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Откройте http://127.0.0.1:8033 . В IDE выберите `.venv/bin/python` и нажмите Run в `main.py` без параметров; `run_local.py` также сохранён как локальный вход. Данные и сохранённые демонстрационные модели входят в репозиторий. Личные задания и ключ браузерной сессии сохраняются в `.local`. Остановка — Stop или Ctrl+C.

```sh
.venv/bin/python run_local.py --check
.venv/bin/python -m unittest discover -v
.venv/bin/python main.py --help
.venv/bin/python scripts/execute_notebook.py
```

[Команды обучения и анализа](docs/CLI.md) доступны через `main.py`; notebook — `notebooks/research.ipynb`. Локальное ядро notebook создаётся внутри `.local`. Пошаговый запуск — [docs/LOCAL_RUN.md](docs/LOCAL_RUN.md), математика и ограничения — [docs/MATHEMATICS.md](docs/MATHEMATICS.md), фактические проверки — [docs/TESTING.md](docs/TESTING.md).

Перед обучением кнопка «Проверить настройки» проверяет контракт, входные признаки и независимое разбиение без запуска моделей. «Остановить обучение» завершает собственный эксперимент после текущего этапа или эпохи; незавершённая модель не предлагается для прогноза. CSV ограничен50 000 строк,256 колонок,2 000 000 ячеек и256 Ки символов на запись; у обучения и прогноза действуют более строгие пределы интерфейса.

Обучение сериализовано между копиями приложения для одной папки проекта. Прерванные новые задания распознаются по владению слотом, их исходники сохраняются для нового запуска. В истории есть страницы старых результатов; завершённый, ошибочный или остановленный эксперимент можно удалить после подтверждения. Активное задание сначала нужно остановить. При ошибке удаления файлов результат исчезает из списка, а интерфейс сообщает об ожидающей очистке.

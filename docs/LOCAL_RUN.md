# Локальный запуск

1. Откройте корневую папку проекта в Python IDE.
2. Создайте виртуальное окружение Python 3.12+ и установите зависимости:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

3. Выберите `.venv/bin/python` как интерпретатор проекта.
4. Откройте `run_local.py` и нажмите Run. Параметры запуска не нужны.

Из терминала:

```sh
.venv/bin/python run_local.py
```

Адрес приложения: http://127.0.0.1:8033 . Остановка — Stop в IDE или Ctrl+C. Сервер запускается одним процессом и доступен только на этом компьютере. Рабочий каталог устанавливается автоматически, поэтому запуск файла из другого каталога не меняет расположение данных.

Проверка подготовки без сервера:

```sh
.venv/bin/python run_local.py --check
```

Данные и модели демонстрационного сценария входят в репозиторий. Выбор модели выполняется по validation, симуляционные данные помечены явно. Приватные задания и ключ браузерной сессии хранятся в .local и не входят в Git. CLI-команды анализа и обучения по-прежнему доступны через main.py.

Если стандартный порт занят другим процессом, оставьте его работающим и выберите другой: `python run_local.py --port 8121`. Параметр можно задать и в конфигурации запуска IDE.

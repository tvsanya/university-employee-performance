# Источник CSV в интерфейсе

Обе формы принимают один источник: локальный CSV либо HTTP/HTTPS-ссылку. Проверка, прогноз и обучение читают те же байты и применяют общие ограничения20МиБ/UTF-8/структуры. Для обучения сохраняются независимые выборки, контракт и SHA фактически загруженного CSV. Адрес не становится путём локального файла и не попадает в профиль данных или архив как учётные сведения.

Ссылка должна отдавать CSV без входа в аккаунт. Встроенные логин/пароль, фрагменты, неверные порты, управляющие символы и адреса длиннее2048 символов отклоняются. file:// и относительные пути через браузер не поддерживаются. Загрузка начинается только по нажатию кнопки; клиент приложения не передаёт сайту браузерные cookies. Таймаут чтения30секунд и предел размера применяются загрузчиком. Недоступность источника показывается без технического пути/стека.

Для ZIP с выбранным CSV остаётся явный CLI-сценарий с member; формы принимают готовый CSV. Выбор ссылки не подтверждает происхождение, лицензию или реальность данных. Маркер synthetic сохраняет учебное назначение development_demo_only.

Проверки включают настоящий локальный HTTP-источник CSV в изолированном тесте, профиль, передачу скачанных байтов обучению, неоднозначный выбор, некорректные схемы/адреса и CSRF. Проверка передачи в очередь использует заглушку только на границе submit; реальное обучение проверяется отдельными интеграционными и браузерными сценариями.

# Чистая локальная установка

`.venv/bin/python scripts/verify_local_install.py` копирует отслеживаемые исходники, данные и модели в отдельный временный каталог. Новый venv устанавливает зафиксированные зависимости. Проверяются pip check, локальный launcher, весь набор unittest, фактическое исполнение notebook с обучением/анализами и прогноз комплектной JSON-модели. Затем настоящий Flask-сервер запускается из другого cwd; главная/CSS проверяются по HTTP на loopback. Собственный процесс завершается, временные данные удаляются.

23 ноября 2026 пройдены73 теста и14 кодовых ячеек notebook в новом окружении. Это функциональная проверка комплекта; визуальная приёмка браузером остаётся открытой. SHA исходников и версии сохранены в reports/local-install-v1.json. Симуляционное происхождение сохраняется и не закрывает академический критерий реальных данных.

## Приёмка в настоящем Chrome

Отдельное окружение: `python3 -m venv .qa-venv`, `.qa-venv/bin/python -m pip install -r requirements-qa.txt`. Проверка: `.qa-venv/bin/python scripts/verify_browser.py --app-python .venv/bin/python`.

Скрипт делает временную копию отслеживаемого комплекта. Реальный локальный HTTP-источник отдаёт3000 симуляционных строк; формы GUI получают профиль и прогноз, сохраняют CSV с флагами просмотра. Затем настоящий фоновый worker обучает baseline и двеDL-настройки, выполняет пятьvalidation-анализов, отдаёт ZIP с проверяемымиSHA и применяет выбранную модель. Другая браузерная сессия получает404 на чужой эксперимент. Для быстрого браузерного испытания выбраны две эпохи: это не повтор полного исследовательского обучения.

Chrome157 прошёл девять проверок, desktop1440/mobile390. Исправлен выход таблицы прогноза за границы мобильной сетки; метрики/результаты прокручиваются внутри доступных с клавиатуры блоков. Шесть снимков reports/local-visual-v1 просмотрены. Временные браузер, HTTP-источник, сервер и данные удаляются; пользовательские модели/сессии не затрагиваются. Это один браузер и симуляция, не полный аудит доступности или валидности оценки реальных людей.

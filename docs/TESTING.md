# Проверка программы

На текущем этапе проходят 57 автоматических сценариев. Тестовые фикстуры не являются исследовательскими данными; сквозной ноутбук и сохранённые демонстрационные артефакты используют явно помеченную симуляцию.

| Подход | Проверяемое свойство | Где воспроизводится |
| --- | --- | --- |
| Модульные проверки | Контракт, признаки, подготовка, метрики, параметры моделей | tests/test_experiment.py, test_preprocessing.py, test_neural.py |
| Интеграционные сценарии | CSV, split, сохранение моделей, GUI-обучение, архив и повторный прогноз | tests/test_baselines.py, test_tuning.py, test_jobs.py |
| Границы и отрицательные входы | Чужая сессия, повреждённый JSON/хеш, отсутствующая колонка, недопустимые числа, размеры, параллельный запуск | tests/test_data.py, test_prediction.py, test_gui.py, test_jobs.py |
| Сравнение независимых реализаций | JSON-вероятности и прогнозы совпадают с исходными sklearn Pipeline | tests/test_prediction.py, test_portable_baseline.py |
| Воспроизводимость | Повторяются split/история/веса; изменение test не меняет выбор и обучение | tests/test_splitting.py, test_neural.py, test_tuning.py |
| Сквозное исполнение | Все шаги заново выполняются одним проектным ядром | scripts/execute_notebook.py |

Команды: `.venv/bin/python -m unittest discover -v`, `.venv/bin/python scripts/execute_notebook.py`, `node --check university_analytics/web/static/app.js`, `.venv/bin/python -m pip check`.

Графики истории и ошибок визуально проверены. HTML-интерфейс проверен Flask test client и синтаксической проверкой JavaScript; полноценная браузерная визуальная проверка ещё не выполнена. Чистое окружение на отдельной установке, окончательная комплектность и количественные критерии исходного задания остаются отдельными проверками.

Предварительный подсчёт Python-пакета без тестов, комментариев, docstring, Notebook и HTML/JS: 1765 непустых физических строк, 1629 логических инструкций. Это не подтверждение выполнения порога 2000 алгоритмических строк; раздувание данных/разметки/сериализованных весов в этот показатель не включается.

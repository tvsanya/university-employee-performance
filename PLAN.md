Тема: «Автоматизация процессов оценки эффективности работы сотрудника университета с применением интеллектуального анализа данных».

Автор: Бакулин Александр Максимович. GitHub: `tvsanya`.
Репозиторий: https://github.com/tvsanya/university-employee-performance

## С чего начинаем

Пользователь выбрал симуляционные данные 20 ноября. Разработка продолжается на явно маркированном сценарии условных преподавателей: 1500 сотрудников, два периода, искусственная категория эффективности из скрытого фактора. Реальная исследовательская пригодность не заявляется; формальное требование реального набора остаётся открытым.

Архитектура сервиса: источник данных → подготовка признаков → базовая модель и DL-модель → оценка качества → интерфейс. Бэкенд связывает модель, интерфейс и хранилище данных/экспериментов. Рабочая DL-архитектура — табличная MLP с двумя скрытыми слоями, внешней групповой validation и сохранением лучшего checkpoint.

## Коммиты

- Цель — не менее 50 содержательных коммитов от имени студента в течение практики и подготовки ВКР, распределённых по нескольким реальным дням работы.
- Ориентир — около 8–10 содержательных изменений в дни активной разработки; фактическое число зависит от выполненных задач. Проверяем число подходящих коммитов ежедневно, чтобы не оставлять требование на последний день.
- Каждый коммит фиксирует самостоятельное изменение: обработку данных, обучение, исправление, интерфейс или проверку. Одно изменение — понятное сообщение коммита.
- Первичную загрузку и коммиты только с добавлением/удалением готовых файлов в целевые 50 не включаем. Даты соответствуют фактической работе.

## Проверяем перед сдачей

- Реальные данные, минимум 1000 строк и 10 колонок; загрузка по ссылке.
- Метрики на train/validation/test, анализ ошибок, сравнение базовой и улучшенной моделей.
- Accuracy ≥ 70% либо другая метрика, согласованная с руководителем.
- Не менее 2000 логических строк собственного алгоритмического кода по индивидуальному заданию.
- В репозитории: `main.py`, `.ipynb`, сохранённые модели, `requirements.txt` с версиями и README с инструкцией запуска.
- Рабочий интерфейс для загрузки данных, обучения, применения моделей и просмотра результатов; математическое описание модели и отчёт.

# Исследовательский пакет эксперимента

После нового GUI-обучения доступны «Исследовательский отчёт Markdown» и «Происхождение и SHA анализов JSON». Оба входят в полный ZIP. Пакет создаётся из уже рассчитанных пяти validation-анализов выбранного семейства: повторного обучения, подбора по test или пересчёта bootstrap не происходит.

Перед сборкой повторно проверяются модель, контракт и split. Каждый сохранённый JSON обязан иметь совпадающие model/source/split SHA и допустимый статус. Исходные байты анализов копируются без изменения; manifest содержит их SHA. При расхождении происхождения пакет не публикуется частично, эксперимент получает отказ. Недоступный по предметной причине анализ сохраняет status=unavailable, исходный JSON и причину; итоговый пакет partial, это показано в GUI. Повреждённый JSON не выдаётся за неприменимый анализ.

analysis_source=existing_snapshot отличает GUI-снимок от CLI research-report, который по умолчанию заново рассчитывает анализы с собственными параметрами. Поэтому число повторов берётся из конкретного JSON, а не предполагается одинаковым. Для ранее созданных GUI-экспериментов, где пакета не было, новые ссылки не предлагаются.

Выдача сохраняет проверку браузерной сессии; ZIP содержит личный входной CSV, но не служебный идентификатор владельца. Markdown экранирует пользовательский текст и сохраняет ограничения интерпретации. Симуляционный пакет не является исследованием реальных сотрудников.

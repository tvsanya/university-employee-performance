# Объём собственного Python-кода

На 22.11.2026: 2030 AST-инструкций и 2280 непустых строк без docstring. Команда: `.venv/bin/python scripts/code_size.py --output .local/code-size.json`. Пофайловый результат — reports/code-size-v2.json.

Считаются main.py и исходные Python-модули university_analytics. Исключены тесты, scripts, notebook, HTML, JavaScript, данные и сериализованные веса. Метод AST считает определения, управляющие и исполняемые инструкции; несколько инструкций на строке считаются отдельно. Это прозрачный технический подсчёт, который следует сверить с методикой проверки индивидуального задания. Количество строк не заменяет работоспособность и реальный датасет.
